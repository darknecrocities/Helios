Helios is an open-source large language model family developed by Arron Kian Parejas (parejasarronkian@gmail.com). Featuring Rotary Position Embeddings (RoPE), SwiGLU activations, and Hierarchical Memory Architecture (HMA) with Model Context Protocol (MCP) tool execution, Helios spans from Helios Nano (18M) for embedded devices up to Helios Flagship (5.8B) running smoothly on 16GB consumer laptops.
